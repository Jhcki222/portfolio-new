## 구성 변경

- 목록: 서비스 소개 아래 역할과 핵심 기여 두 항목, 주요 기술을 표시한다. 성능 수치는 상세 본문과 표에 둔다.
- 상세: 개요, 개인 기여, 시스템 구성, 기술 사례 순서로 정리한다. 이유는 짧은 문단으로, 구현과 결과는 목록으로 작성한다.
- 노후하우는 인증, 상품 검색 및 수집, 통계 조회, 사용자 갱신 및 재처리의 네 사례로 통합했다.
- 대안 검토, 운영 성과, 회고를 새 사실처럼 만들지 않았다. 확인된 제약과 선택 근거를 해당 사례에 연결했다.
- 챗봇은 동일한 프로젝트 데이터의 기여 요약과 수정된 본문을 사용한다.

추가 증빙이 있으면 평가 질의 수, 비교 버전, Lighthouse 세부 지표, 부하 테스트의 DB 설정을 보완할 수 있다. 이 항목들은 공개 원고에서 완료 성과로 추가하지 않았다.
