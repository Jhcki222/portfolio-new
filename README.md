# Portfolio

## 파일 구조

```text
portfolio/
├── index.html
├── README.md
├── assets/
│   └── 정적 이미지 및 에셋
├── css/
│   └── style.css
└── js/
    ├── main.js
    ├── data.js
    ├── render.js
    ├── navigation.js
    └── commandBar.js
```

- `index.html`: SPA의 전체 섹션 구조와 페이지 진입점입니다.
- `css/style.css`: 레이아웃, 반응형 규칙, 시각 스타일을 관리합니다.
- `js/main.js`: 애플리케이션 초기화 진입점입니다.
- `js/data.js`: 경험, 프로젝트, 기술 스택, 커맨드 키워드 데이터를 관리합니다.
- `js/render.js`: 동적으로 표시되는 섹션 렌더링을 담당합니다.
- `js/navigation.js`: 섹션 탭 활성화와 모바일 메뉴 동작을 담당합니다.
- `js/commandBar.js`: 첫 화면 커맨드 입력창과 타이핑 효과를 담당합니다.
- `assets/`: 페이지에서 사용하는 정적 에셋을 보관합니다.
